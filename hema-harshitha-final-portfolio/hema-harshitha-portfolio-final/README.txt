HEMA HARSHITHA ARLI — INTERACTIVE PORTFOLIO
============================================

This is the new app-style portfolio. Only the Home section is shown initially.
Click a navigation button or one of the Home shortcut cards to replace the
current section with the selected section. It does not display all sections
as one long page.

FEATURES
- Midnight dark theme with gold and electric-blue accents
- Switchable Gold, Blue and Violet color themes
- App-like section navigation (Home, About, Education, Skills, Projects,
  Certifications, Achievements, HEMAZHUB, Contact)
- Responsive desktop and mobile navigation
- Profile photograph and MentiBY workshop certificate included
- Sports Fest and Campus Lost & Found live project links included

RUN LOCALLY
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open index.html with Live Server.
4. Click each navigation button and test the theme dots.

FILES
- index.html
- style.css
- script.js
- assets/profile-photo.png
- assets/mentiby-workshop-certificate.pdf

BEFORE DEPLOYING
- Check all details and links.
- The GitHub contact link currently points to the generic GitHub account
  page supplied earlier. Replace it with your actual profile URL when ready.
- Add the chess certificate image/PDF when available.
- Add a downloadable resume only after you provide the final PDF.
- Confirm you are comfortable making your email and photo public.

GITHUB PAGES
1. Create a repository, for example: hema-harshitha-portfolio.
2. Upload the contents of this folder (do not upload the ZIP itself).
3. Go to Settings -> Pages.
4. Choose Deploy from a branch, branch main, folder /(root), then Save.
5. Wait for GitHub Pages to show the published URL.
6. Test the public URL on desktop and mobile before sharing it on LinkedIn.

No backend or Firebase setup is required. Google Fonts are loaded online, with
fallback fonts available.
